Feature Walkthrough & Key Screenshots

Explore how this module enhances the standard Odoo pricelist interface with financial matrix capabilities.

1

Comprehensive Price Rules Overview

Seamlessly displays extended financial metrics including Cost, Profit, and Profit Margin (%) directly on the pricelist rules list view. Gain immediate visibility into financial rule metrics across default or custom pricelists without opening individual records.

2

Advanced Grouping & Multi-Field Search

Organize price rules effortlessly by grouping them by Product Name, Product Category, or Applied Item. Full search integration allows filtering through all visible columns and financial metrics dynamically.

3

Fast Inline Financial Field Editing

Edit values directly inline inside the grid! Clicking on cells like Profit or Price updates the rule instantly in real-time (applicable for fixed price or discount rule types), eliminating repetitive form navigation.

4

Quick Rule Creation Modal

Create new price rules without losing your place in the matrix. Clicking the "New" button launches an intuitive dialog window allowing quick configuration of rule types, minimum quantities, fixed prices, and validity periods.
