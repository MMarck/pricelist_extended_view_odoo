Pricelist Rules Manager

See, search and edit every rule of your pricelist in a single list view, right inside the Sales app.

SalesPricelistsOdoo Apps

All price rules of a pricelist, in one place

Odoo shows pricelist rules inside the pricelist form, one pricelist at a time and with little context. This module adds a dedicated list of the rules that belong to the Default pricelist, with cost, profit and margin visible on every line.

A clear list of every rule

Open Sales › Pricelists › Price Rules to see all rules of the Default (USD) pricelist together.

  • Rule name, type and what it applies on (product, variant or category)
  • Applied item, cost, profit and profit margin (%)
  • Minimum quantity for each rule
  • Quick access to sales of the product

Search and group by product

Find the rule you need in seconds. Search using any of the visible fields and group the list by product name to compare all the rules of one product at a glance.

  • Group totals for cost, profit and margin
  • Expand or collapse each product group
  • Filter by product, category or rule

Edit values directly in the list

Click any cell, such as Profit, type a new value and save. The change is written back to the pricelist rule, so there is no need to open each rule.

Inline editing updates the rule definition for Fixed Price and Discount rules only.

Create new rules with the New button

Click New in the list to open the rule form without leaving the view.

  • Apply to a product or a category
  • Choose the price type: Discount, Formula or Fixed Price
  • Set the minimum quantity and the validity period
Compatible with the Odoo Sales app. Requires the Sales module.
